Guide

What is this?

A place to write and check a Bible translation. It shows files in three formats as one Bible, and converts between them.

  • Bible Markdown (.md): plain text that is easy to type, like the examples below.
  • USFM (.usfm, .sfm): the standard format used by Paratext and most Bible software.
  • Bible HTML (.html): a web page that can be styled with a stylesheet.

First steps

  1. Press Open folder (or Open files or zip), or try the example.
  2. Pick a book on the left, then a chapter number.
  3. Edit in the left pane; the preview on the right updates as you type.
  4. Press Convert… to make another format.

Writing Bible Markdown

WriteYou get
# Romans (ROM)The start of the book Romans
1:1 In the beginning…Chapter 1, verse 1
… end. 2 Next verseA verse number is a number followed by a space
483\ yearsA real number in the text (the backslash stops it being a verse number)
### A headingA section heading
/ A line of poetryPoetry; extra spaces after / indent the line
[added words]Words added for clarity
Lord^Small capitals (LORD)
some {words} here
{words}: the note		A footnote on “words”; the note text goes below the paragraph
- itemA list item
>>>>>>>>>> … >>>>>>>>>>An explanatory note in regular Markdown (an introduction before chapter 1)
```bible John 3:16 … ```A quoted passage inside a note; its numbers are not counted as verses

Where are my files?

In Chrome and Edge, files stay in your folder and are saved automatically. In other browsers they are kept inside the browser; press Download project to save a copy to your computer.

Seeing what a button does
